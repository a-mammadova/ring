#B12CL

B12CL is a location-based reminder application.

users can create reminders based on location and a radius. the app is designed to notify the user when they enter the specified area

## current status

backend currently provides rest api for creating, retrieving, updating and deleting reminders

## tech stack

### backend
- java
- spring boot
- spring web

### frontend
- html
- css
- leaflet.js
(leaflet.js is coming soon, and i'll work on the frontend later)
